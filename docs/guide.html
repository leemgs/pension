📖 사용 가이드

처음 사용하는 분을 위한 기본 흐름입니다. 항목별 설명과 활용 예는 사용자 매뉴얼을 보세요.

1. 기본 설정 입력

기본 시간축·물가·세법/건보료 설정에서 현재 나이, 종료 나이, 물가상승률을 정합니다.

2. 자산별 변수 조정

자산별 상세 변수에서 근로소득, 국민연금, 퇴직연금 DC, IRP, 연금저축, 개인연금, 주식투자, 주택연금을 각각 켜고 끄며 값을 조절합니다. 금액 단위는 백만원입니다(예: 1.5 = 150만원).

3. 결과 확인

  • 핵심 요약 지표: 월평균 세전·세후 현금흐름, 발생비용, 종료 시점 잔여 재산
  • 월간 현금흐름 그래프: 명목가치/현재가치, 연단위/월단위 전환
  • 연령별 상세 표: 세금·건보료 내역과 CSV 저장

4. 목표 현금흐름 맞추기

목표 CIF 자동조절을 켜면 목표 월 현금흐름에 부족한 금액을 지정한 우선순위의 자산에서 자동으로 인출하고, 최적 조합을 추천받을 수 있습니다.

5. 저장과 백업

현재 상태는 브라우저에 자동 저장됩니다. 상단의 내보내기/불러오기 버튼으로 JSON 파일 백업·이동이 가능합니다.

자주 하는 실수

  • 금액을 원 단위로 입력 — 모든 입력은 백만원 단위입니다.
  • 건보료율 등이 해당 연도와 맞는지 확인하지 않음 — 설정 패널에서 수정할 수 있습니다.
⚠️ 결과는 입력 가정에 따른 참고용 추정치이며 세무·재무·법률 자문이 아닙니다. 중요한 결정 전에는 공식 자료와 전문가를 통해 확인하세요.
