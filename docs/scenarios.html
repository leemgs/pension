🗂️ 시나리오

기본 제공되는 은퇴 플랜입니다. 버튼을 누르면 해당 시나리오가 적용된 시뮬레이터가 바로 열립니다.

1. 표준 균형 은퇴 플랜 (기본)

60세 사적연금·주식배당 개시 → 65세 국민연금 → 70세 주택연금 단계별 파이프라인

2. 배당·연금 조기은퇴 플랜 (56세)

56세 조기은퇴 후 고배당 포트폴리오와 연금저축/IRP를 즉시 개시하는 시나리오

이 시나리오로 열기

3. 연기연금 + 주택연금 극대화 플랜

국민연금을 68세로 연기(+21.6% 증액)하고 65세부터 주택연금(비과세)을 적극 활용하는 절세 플랜

이 시나리오로 열기

📘 가이드 사례

학습 자료(연금·투자 가이드)의 예시를 시뮬레이터로 재현한 사례입니다. 열어서 값을 바꿔 보세요.

이 사례로 열기

연금저축 2억 · 65세부터 20년 수령
